# Project Setup Guide for Development

## 1. Clone the repository

```bash
git clone https://github.com/daudk3/flight-management-system
```

## 2. Install Dependencies

After cloning the latest code, run the following command in your command line while in the project directory:

```bash
npm install
```

## 3. Start the server

While in the project directory run the following command to run the server on http://localhost:5173/

```bash
npm run dev
```
