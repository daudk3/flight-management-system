## Frontend
- **Framework:** [Reac](https://react.dev/) (via Vite)
- **Build Tool:** [Vite](https://vitejs.dev/) – fast development and build
- **Routing:** [React Router](https://reactrouter.com/) – navigation between pages (Home, Flights, Admin, Bookings)
- **Styling:**  
  - [Tailwind CSS](https://tailwindcss.com/) – utility-first CSS framework  
  - [Material UI](https://mui.com/) for ready-made components)*
- **Icons & UI Enhancements:** [Lucide React](https://lucide.dev/) or [Heroicons](https://heroicons.com/)
## Backend
- **Database:** [Firebase Firestore](https://firebase.google.com/docs/firestore) – cloud-hosted NoSQL database  
- **Authentication:** [Firebase Auth](https://firebase.google.com/docs/auth) – email/password or Google Sign-In
